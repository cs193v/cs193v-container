#  at /etc/cs193v/setup-git-messages.txt, which also means cs193v.buildhash covers it: reword

#
#  *ASTERISKS MARK EMPHASIS* and are rendered as bright cyan, the same colour the arrow-key
#  menu highlights with. They come in pairs on one line. Nothing that ends up inside a box may
#  use them: box() measures display columns and the markup is removed after it counts, so the

[[token.intro]]
Now that you're on GitHub, you'll need to set up a *fine-grained access token* for the
course. This is what will let you submit your homework. (We will describe what a
"fine-grained access token" means in more detail later this quarter. For now, think of it as
a password that is only allowed to do a few specific things.)

[[token.prefill]]
*Open this link.* It fills in almost everything for you:

    {{URL}}

Then, on that page:

  1. Under *Repository access*, choose *All repositories*.
  2. Check that *Expiration* reads *{{EXPIRY}}*.
  3. Check that *Repository permissions* lists exactly these:

         Contents         Read and write
         Issues           Read and write
         Pull requests    Read and write
         Metadata         Read-only        (GitHub adds this one for you)

  4. Scroll to the bottom and click *Generate token*.

If that link doesn't work, you can set the same thing up by hand:

[[token.byhand]]
  1. Go to https://github.com/settings/personal-access-tokens
  2. Click *Generate new token*.
  3. For *Token name*, type CS193V.
  4. For *Resource owner*, choose *{{ORG}}*. If you don't see it in the list, you
     haven't accepted your invitation yet — see step 3 above.
  5. For *Expiration*, choose *Custom...* and pick *{{EXPIRY}}*.
  6. For *Repository access*, choose *All repositories*.
  7. Open *Repository permissions* and set *Contents*, *Issues* and *Pull requests*
     each to *Read and write*.
  8. Scroll to the bottom and click *Generate token*.

[[token.paste]]
When you are done, copy your access token and paste it here. Also, make sure to save it in a
safe place; once you close the window with the token in it, you won't be able to see it again!

Your token itself will not appear on the screen. That is on purpose — it keeps your token from
staying visible in this window. What you will see instead is a row of dots with a count of the
characters in it, so you can tell that your paste landed.

[[err.clone]]
*Oh no, we can't reach the course's practice repository!*

Your access token was accepted by GitHub, so this is almost certainly about what the token is
allowed to do. Please check these, in this order:

1. *Resource owner.* Open https://github.com/settings/personal-access-tokens and click your
   CS193V token. *Resource owner* must read *{{ORG}}*, not your own username. If it reads
   your username, that token cannot see any course repository, and you will need to make a
   new one — resource owner cannot be changed after a token has been created.

2. *Repository access.* On the same page, this must be *All repositories*.

3. *Contents.* Under *Repository permissions*, *Contents* must be *Read and write*. If you
   change it, click *Update token* at the bottom.

4. *Your invitation.* If you have not accepted your invitation to {{ORG}} yet, do that
   first, then come back: https://github.com/orgs/{{ORG}}/invitation

[[err.clone-wrong-owner]]
*Oh no, your access token belongs to the wrong account!*

The token you pasted was created with *@{{LOGIN}}* as its *Resource owner*, which means it can
only reach your own repositories — not the course's. It needs to be *{{ORG}}* instead.

Resource owner cannot be changed after a token has been created, so this one cannot be fixed
and you will need to make a new one. When you do, the *Resource owner* box is the second thing
on the page, above *Repository access*:

    https://github.com/settings/personal-access-tokens

You can delete the old token from that same page once the new one works.

[[err.push]]
*Oh no, we can't* git push*!*

This is most likely because your access token's *Contents* permission is set to *Read-only*
instead of *Read and write*. To correct this:

  1. Open https://github.com/settings/personal-access-tokens
  2. Click your *CS193V* token.
  3. Scroll to *Repository permissions* and set *Contents* to *Read and write*.
  4. Scroll to the bottom and click *Update token*.

You do not need to make a new token, and your token will not change — you can keep using the
one you already pasted.

[[err.issues]]
*Oh no, we can't work with GitHub issues!*

This is most likely because your access token's *Issues* permission is not set to *Read and
write*. To correct this:

  1. Open https://github.com/settings/personal-access-tokens
  2. Click your *CS193V* token.
  3. Scroll to *Repository permissions* and set *Issues* to *Read and write*.
  4. Scroll to the bottom and click *Update token*.

You do not need to make a new token, and your token will not change — you can keep using the
one you already pasted.

[[err.prs]]
*Oh no, we can't work with pull requests!*

This is most likely because your access token's *Pull requests* permission is not set to
*Read and write*. To correct this:

  1. Open https://github.com/settings/personal-access-tokens
  2. Click your *CS193V* token.
  3. Scroll to *Repository permissions* and set *Pull requests* to *Read and write*.
  4. Scroll to the bottom and click *Update token*.

You do not need to make a new token, and your token will not change — you can keep using the
one you already pasted.

[[err.network]]
*Oh no, we can't reach GitHub!*

This usually means the network isn't working, rather than anything being wrong with your
setup. Check that you can load https://github.com in your browser, then run *setup-git*
again.

[[err.rate-limit]]
*GitHub has asked us to slow down.*

This happens when a lot of people set things up at the same time. Wait a minute, then run
*setup-git* again.
